# ZK Finance — демо

Демонстрационная версия сайта и CRM-хаба компании исламской рассрочки.

**Открыть:** https://hanmegait95.github.io/zk-finance-demo/

## Что внутри

Один самодостаточный `index.html` без сборки и зависимостей, кроме шрифта Manrope
с Google Fonts.

- `/` — публичный сайт: калькулятор мурабахи с этапами расчёта, продукты,
  сравнение с кредитом, кейсы, документы, шариатский совет, многошаговая заявка
- `/#/hub` — CRM: дашборд, воронка заявок с перетаскиванием, клиенты, договоры
  с графиками платежей, реестр платежей, шариат-контроль, аналитика, настройки

Вход в CRM демонстрационный — пароль не требуется, роль выбирается из списка.
Заявка, отправленная на сайте, появляется в воронке CRM.

## Данные

Все компании, договоры, клиенты, ФИО и суммы вымышлены и приведены
исключительно для демонстрации интерфейса.
